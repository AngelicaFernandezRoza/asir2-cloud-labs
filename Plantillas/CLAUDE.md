# Contexto del proyecto

Plantillas Terraform de introducción a AWS para estudiantes 
universitarios sin conocimientos previos de AWS ni de Terraform.
El objetivo es que la documentación les sirva para entender 
qué hace cada parte del código, no solo usarlo.

## Idioma
Toda la documentación se genera en español.

## Audiencia
Estudiantes que ven Terraform y AWS por primera vez. Cuando llegan aquí ya han creado los recursos con la consola. Tienen conocimientos profundos de redes y sistemas operativos. No los tienen de Terraform ni de programación ni de ningún tipo de automatización. 

## Estilo de documentación
- Explicar SIEMPRE qué es cada cosa antes de explicar cómo funciona
- Usar analogías cuando ayuden a entender conceptos de cloud
- Tono didáctico, cercano, sin ser infantil
- Cada bloque de código Terraform debe tener un comentario 
  explicando qué hace y por qué está ahí

## Estructura del README de cada plantilla
1. ¿Qué hace esta plantilla? (explicación en lenguaje llano)
2. ¿Qué recursos de AWS crea? (con explicación de qué es cada recurso)
3. Requisitos previos (Terraform instalado, credenciales AWS...)
4. Cómo usarla (comandos paso a paso con explicación de cada uno)
5. Qué ocurre cuando se ejecuta (qué verán en AWS)
6. Cómo destruir los recursos creados (importante para no generar costes)
